# Pet Adoption App

A mobile application developed using **React Native and Expo** that aims to help users discover and browse pets available for adoption.

## Project Description

The Pet Adoption App provides a simple and user-friendly interface where users can explore available pets, view pet information, and find potential companions for adoption.

This project is developed as part of our academic requirements.

## Technologies Used

- React Native
- Expo
- JavaScript
- NativeWind
- Tailwind CSS
- Git and GitHub

## Planned Features

- **Home Screen:** Displays featured pets and adoption categories.
- **Browse Pets:** View available pets for adoption.
- **Search and Filter:** Find pets based on name or category.
- **Pet Details:** View information about a selected pet.
- **Favorites:** Save pets to a favorites list.
- **API Integration:** Retrieve pet information from an API.

## Installation and Setup

1. Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. Navigate to the project folder:

```bash
cd pet-adoption
```

3. Install dependencies:

```bash
npm install
```

4. Start the Expo development server:

```bash
npx expo start
```

5. Choose how to preview the application:
   - Press `a` to open Android Emulator.
   - Press `w` to open the web preview.
   - Scan the QR code using Expo Go on your Android phone.
